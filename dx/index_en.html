FAQ

Frequently asked questions

Regarding the frequently asked questions inquiries, we will post the answer.

Please let me know the specifications of the available computer.

You need a CPU of Core i7 or higher and 8GB or more of memory in Windows environments.
For macOS environment, a CPU of M1 or higher and 8GB or more of memory are required.

Do you need a GPU?

ailia DX Insight can be executed using only a CPU.
When using a compatible GPU (such as the built-in GPU of the Intel® Core™ Ultra series or the Intel® Arc™ GPU), high-speed processing is possible for document registration and minutes creation.

Can I use the shared folder?

ailia DX Insight can handle mounted files, so it can also use shared folders via the network.

Please tell me the supported file formats.

It supports the following document formats.
'c', 'cpp', 'csv', 'json', 'java', 'md', 'py', 'rb', 'tex', 'txt', 'css', 'php', 'pdf', 'docx', 'xlsx'

It supports the following image formats.
'png', 'jpg', 'jpeg'

It supports the following audio formats.
'wav'

Can it be used without a ChatGPT API KEY?

ailia DX Insight supports ChatGPT, Gemini, Azure, OpenAI-compatible servers, and local LLM.
When using a local LLM, it can be used without a ChatGPT API KEY.
Additionally, since meeting minutes and image searches, as well as OCR, are always processed locally, they can be used without a ChatGPT API KEY.

Please tell me the price.

ailia DX Insight can be used completely free of charge. No account creation or email address registration is required, and it is free for commercial use.
