FUNCTION

機密業務はローカルLLMで、
一般業務はクラウドLLMで。

「DX Insight」は、社外秘データはローカルLLMですべて端末内で処理、
一般業務はChatGPT・Claude・Geminiから最適なモデルを選択——
機密度に応じてAIを使い分けられる統合AIアプリです。

金融・医療・法務・研究開発の機密業務から、日々のドキュメント作成まで。
機密会議の議事録、社外秘文書の翻訳、画像検索もひとつの画面で完結します。

チャット

メールのドラフトや契約書の確認、ファイル・画像を読み込んでの対話まで。機密度に応じてローカルLLMとクラウドLLMを使い分けられます。

RAG

フォルダ単位で社内文書を取り込み、根拠を示しながら回答。機密文書も端末内のローカルLLMで安全に参照できます。

情報検索

キーワードからAIが画像の内容や音声の特徴を理解し、該当ファイルを検索。機密性の高い画像・音声もローカルで安全に扱えます。

翻訳

PDF2PDFでレイアウトを保ったまま多言語化。長文翻訳や校正も、社外秘文書を外部に送信せずローカルLLMで処理できます。

議事録作成

会議の発言を話者ごとに分離して自動で書き起こし、終了と同時に議事録が完成。録音ファイルからの作成や英語翻訳にも対応します。

画像生成・音声合成

テキストから画像を生成・編集。dall-e-3／gpt-image-1／Gemini 2.5 Flashを用途で選択でき、日本語対応のリアルタイム音声合成も搭載します。

FAQ

よくあるご質問

お問い合わせの多いご質問について、回答を掲載させていただきます。

利用可能なパソコンのスペックを教えてください。

windows環境ではCore i7以上のCPUと、8GB以上のメモリが必要です。
macOS環境ではM1以上のCPUと、8GB以上のメモリが必要です。

GPUは必要ですか？

DX InsightはCPUのみでも実行可能です。
対応するGPU（Intel® Core™ Ultra シリーズの内蔵GPU、Intel® Arc™ GPU など）を使用した場合、ドキュメントの登録や議事録作成などで高速処理が可能です。

共有フォルダは使用できますか？

DX Insightはマウントされたファイルを扱うことができるため、ネットワーク経由の共有フォルダも使用可能です。

対応しているファイルフォーマットを教えてください。

下記のドキュメントフォーマットに対応しています。
'c', 'cpp', 'csv', 'json', 'java', 'md', 'py', 'rb', 'tex', 'txt', 'css', 'php', 'pdf', 'docx', 'xlsx'
下記の画像フォーマットに対応しています。
'png', 'jpg', 'jpeg'
下記の音声フォーマットに対応しています。
'wav'

ChatGPT のAPI KEY がなくても使用できますか？

DX Insightは、ローカルLLM、OpenAI（ChatGPT）、Anthropic（Claude）、Google（Gemini）、Azure、OpenAI互換サーバに対応しています。
ローカルLLMを使用する場合、ChatGPTのAPI KEY がなくても使用可能です。
また、議事録と画像検索、OCRについては常にローカルで処理されるため、ChatGPTのAPI KEY がなくても使用可能です。

価格を教えてください。

現在は評価版として1年間無償でご利用いただけるライセンスでご利用いただけます。
